# Experiment protocol (week 2, block B)

Pair: ______________   Option: 1 Tree and threshold · 2 More features · 3 Validation over time

| | |
|---|---|
| **Hypothesis** (written before the run): what do you expect and why? | |
| **Experiment**: what did you change (exactly one thing)? Data, split, metric | |
| **Result**: numbers with the number of events behind them; one figure or table | |
| **Conclusion**: confirmed, rejected or open? Next step? What remains uncertain? | |

Rules: one change at a time · time split only (first 70 % train, last 30 % test) · report events, not only percentages.
Pitch: 60 seconds per pair, one slide or this protocol.
